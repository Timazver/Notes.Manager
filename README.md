# NotesManager

NotesManager — веб-API для управления заметками, реализованный на ASP.NET Core и .NET.

## Требования

- .NET SDK
- настроенное подключение к базе данных
- переменные окружения для создания первоначального администратора

## AdminBootstrap

При запуске приложения `AdminBootstrap` выполняется как фоновый процесс, зарегистрированный через `IHostedService`.

Сервис проверяет наличие администратора с указанным email. Если пользователь ещё не существует, сервис создаёт его и
назначает ему роль администратора. Повторный запуск приложения не должен создавать дубликат пользователя.

Данные администратора не хранятся в исходном коде или `appsettings.json`. Их необходимо передавать через переменные
окружения:

| Параметр    | Переменная окружения | Описание               |
|-------------|----------------------|------------------------|
| `firstName` | `ADMIN_FIRST_NAME`   | Имя администратора     |
| `lastName`  | `ADMIN_LAST_NAME`    | Фамилия администратора |
| `email`     | `ADMIN_EMAIL`        | Email для входа        |
| `password`  | `ADMIN_PASSWORD`     | Пароль администратора  |


### macOS и Linux

```bash
export ADMIN_FIST_NAME="Admin"
export ADMIN_LAST_NAME="User"
export ADMIN_EMAIL="admin@example.com"
export ADMIN_PASSWORD="change-this-password"

dotnet run
```

## Запуск

```bash
dotnet restore
dotnet build
dotnet run
```

Во время запуска `IHostedService` получает параметры `AdminBootstrap` из конфигурации приложения, создаёт scope для
зависимостей с ограниченным временем жизни, проверяет администратора и при необходимости добавляет его в базу данных.

Если обязательная переменная окружения отсутствует или имеет некорректное значение, приложение должно завершить запуск с
понятным сообщением об ошибке.
